# Responsible AI Notes

## Scope
The application provides AI-generated stock analysis for educational and informational use.

## Risks
- hallucinated facts
- outdated data
- overconfidence in recommendations
- user overreliance on generated outputs

## Mitigations
- RAG grounding with retrieved documents
- explicit disclaimers
- confidence/risk labels
- source citations where possible
- prompts instructing uncertainty acknowledgement
- restricted stock universe

## Prohibited Behavior
- guaranteed returns
- unsupported claims
- hidden confidence inflation
- misleading certainty

## Human Oversight
Users should validate outputs and consult qualified financial advisors.
