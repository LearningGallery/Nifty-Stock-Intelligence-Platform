# User Guide

## What This App Does
This chatbot analyzes selected Indian stocks from the supported market universe using:
- market data
- financial metrics
- technical indicators
- recent news
- optional uploaded reports

## Example Questions
- Analyze TCS for short-term trading
- Compare Infosys and Wipro
- What are the risks in this stock?
- Summarize the uploaded annual report
- What does the annual report say about future growth?

## Uploading Documents
1. Open Chat
2. Upload annual report PDF
3. Wait for processing
4. Ask questions about the uploaded document

## Understanding Recommendations
- **BUY**: favorable setup with defined risks
- **HOLD**: mixed or balanced setup
- **SELL**: unfavorable risk/reward or bearish signals
