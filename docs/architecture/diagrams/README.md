# Diagrams

## Mermaid Support
This repository uses Mermaid for portable, text-based diagrams.

## Limitation
Mermaid does not support official AWS architecture icons natively.

## Recommended Approach
For polished portfolio visuals:
1. Create draw.io diagrams using AWS Architecture Icons
2. Store source files in `docs/architecture/diagrams/draw.io/`
3. Export PNG/SVG into an `assets/` subfolder if desired

## Suggested Draw.io Files
- hld.drawio
- lld.drawio
- runtime.drawio
- deployment.drawio
- rag-flow.drawio
